## 我们怎么理解「自成长」

大多数 AI 技能是一次性的：这次问、这次答，下次从零开始。
"越用越懂你"的关键不在模型更聪明，而在**技能自己带记忆、带反馈闭环**——
每次使用都往用户画像里沉淀一点，下次直接用上，用户不需要重复交代同一件事。

本仓库两个 Skill 都围绕这一条来设计：**画像文件 + 反馈信号 + 下次自动生效**。

| Skill | 解决的问题 | 自成长机制 |
|---|---|---|
| [`k12-stem-tutor-waisc`](./k12-stem-tutor-waisc/) | 家长辅导 K12 数理化，讲了还是不会 | 记录每题的错因类型（概念不清 / 计算失误 / 读题偏差），下次自动避开已掌握的、加练薄弱项，讲解深度随掌握度调整 |
| [`ai-text-humanizer-waisc`](./ai-text-humanizer-waisc/) | AI 写的东西一眼假，改得像自己写的很费劲 | 从用户历史文本抽取文风指纹（句长分布、常用连接词、段落节奏、口头习惯），每次改写后吸收用户的手动修订，指纹持续收敛到用户真实文风 |

## 运行说明

两个 Skill 均为**纯 Markdown 声明式技能**，无需安装依赖、无需联网、无需 API Key：

1. 把对应目录下的 `SKILL.md` 放入支持 Agent Skills 的客户端（WorkBuddy / Claude Code / 兼容 SKILL.md 规范的 Agent）的技能目录；
2. 或直接把 `SKILL.md` 内容作为 system prompt 载入；
3. 首次使用会在工作目录建立画像文件（如 `.profile/学生画像.md`、`.profile/文风指纹.md`），后续自动读取与更新。

画像文件是纯文本，用户可随时查看、编辑、删除——**自成长过程对用户完全透明可控**，这是我们刻意的设计取舍。

## 测试样例

每个 Skill 的 `README.md` 中含「测试样例」段：给定示例输入、预期输出，以及**第二次使用时行为应如何变化**（这是验证"自成长"是否真实生效的关键复现步骤）。
