# k12-stem-tutor · 世界AI技能锦标赛参赛包

> 当月赛季主题：**自成长 · 越用越懂你**
> 参赛包标识：`k12-stem-tutor-waisc`

## 定位

一个会"记住学生"的中小学数理化一对一辅导 Skill。它不是一次性答题器，而是每次辅导都沉淀学情：哪类错题反复出现、哪个知识点是根因漏洞、该给什么难度的变式题——**用得越多，越懂这个学生**。

## 场景

- 家长/学生拍一道错题，Skill 先诊断根因，再分步讲，最后给 2 道同类变式验收。
- 连续多天使用后，Skill 自动汇总"薄弱点雷达"，提示优先补哪块。
- 老师用它给全班生成分层练习：同一知识点，按掌握度出不同难度。

## 能力

1. **分步讲解**：不甩答案，按"已知→未知→桥梁"拆解题链。
2. **错题根因诊断**：区分"算错 / 概念错 / 审题错 / 知识断层"，给出对应补救路径。
3. **同类变式生成**：基于原题自动出 2-3 道难度可控的变式，验证真懂。
4. **学情沉淀（自成长核心）**：跨轮记忆学生的薄弱标签，越用画像越准。
5. **知识溯源**：把一个错误回溯到它依赖的前置知识点，补链而非补题。

## 技术底座

- 提示词工程：角色锚定（耐心私教）+ 分步链 + 错题分类器 + 变式生成器。
- 记忆机制：以"学生 ID → 薄弱标签权重表"做轻量长期记忆，实现"越用越懂你"。
- 落地形态：SkillHub `SKILL.md` 技能包，可直接被 Agent 调用，无需额外服务。

## 运行说明

1. 将本目录作为 Skill 加载到支持 SkillHub 技能的 Agent 运行时。
2. 首次使用让学生/家长自报年级与近期错题；后续每轮自动更新学情表。
3. 调用示例指令："讲一下这道力学题，并给我两道变式""我最近哪块最弱？"

## 测试样例

输入（第 1 次）：
> 一元二次方程 x²-5x+6=0 我不会，直接给的答案。

输出：
> 根因判断：你直接要答案 → 偏"概念/步骤跳跃"。我们分步：① 因式分解 (x-2)(x-3)=0 ② 得 x=2 或 3。变式：解 x²-7x+12=0（自测，答不出我再补"十字相乘法"前置）。

输入（第 5 次，同一学生）：
> 我又卡在应用题了。

输出（已沉淀"应用题建模弱"标签）：
> 检测到你前 4 次有 3 次卡在"文字→方程建模"，本次优先用"画量关系表"法，而不是直接列方程。我们慢一点。
