# ai-text-humanizer · 世界AI技能锦标赛参赛包

> 当月赛季主题：**自成长 · 越用越懂你**
> 参赛包标识：`ai-text-humanizer-waisc`

## 定位

一个会"学你文风"的去 AI 味改写 Skill。它不仅能把机器腔改自然，还能在多次协作中记住你的表达偏好（口语化还是严谨、爱用短句还是排比），**改得越多，越像你本人**。

## 场景

- 自媒体人把 AI 草稿改成自己的爆款腔，保持人设不塌。
- 职场人把周报从"AI 味"改成老板熟悉的干练风格。
- 学生把论文机翻腔改成学术规范表达，同时保留个人语气。

## 能力

1. **多风格去味**：学术严谨 / 新媒体爆款 / 公文规范 / 口语自然，一键切换。
2. **降重强度分级**：轻改（保原意）/ 中改（调结构）/ 重写（换说法）。
3. **AIGC 检测规避**：打破典型 AI 句法（排比、破折号、三段式、连接词堆砌）。
4. **文风记忆（自成长核心）**：记住用户偏好画像，越用越贴合"你的声音"。
5. **一致性校验**：同一批文稿改写后语气统一，不忽机器忽人。

## 技术底座

- 提示词工程：风格锚定 + 去味规则库 + 强度档位 + 文风记忆槽。
- 记忆机制：以"用户 ID → 文风标签权重"做轻量长期记忆，实现"越用越懂你"。
- 落地形态：SkillHub `SKILL.md` 技能包，可被 Agent 直接调用。

## 运行说明

1. 将本目录作为 Skill 加载到支持 SkillHub 技能的 Agent 运行时。
2. 首次使用选择目标风格与强度；后续轮次自动套用已学的文风画像。
3. 调用示例："把这段改成本人的公众号爆款腔""轻改保原意，别动专业术语"。

## 测试样例

输入（第 1 次）：
> 在当今快节奏的时代，我们需要进一步提升效率。（AI 腔）

输出（选"口语自然"）：
> 现在大家都忙，效率得再提一截。

输入（第 8 次，同一用户，已学"短句+反问"偏好）：
> 由此可见，该方法具有重要价值。

输出（贴合已学文风）：
> 所以这法子值不值？当然值。
